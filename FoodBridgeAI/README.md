
# 🌱 FoodBridge AI

### AI-Based Food Redistribution System

FoodBridge AI is a web-based platform that connects food donors such as restaurants, hotels and supermarkets with NGOs and community kitchens.

## 🎯 Objective

To reduce food wastage and distribute surplus food to people in need.

## ✨ Features

- User registration and login
- Separate Donor and NGO dashboards
- Add and manage food donations
- View available food donations
- NGO food request management
- Food collection tracking
- AI-based donor and NGO matching (planned)

## 🛠️ Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite
- Machine Learning (planned)

## 🚀 How to Run

1. Clone the repository.
2. Install the required packages:

   pip install -r requirements.txt

3. Run the application:

   python app.py

4. Open http://127.0.0.1:5000/ in your browser.
