
# FoodBridge-AI

## AI-Based Food Redistribution System to Reduce Food Waste and Fight Hunger

### Project Overview
FoodBridge-AI is an AI-based food redistribution system designed to reduce food wastage and help fight hunger. It aims to connect food donors with people or organizations in need of food.

### Objectives
- Reduce food wastage.
- Connect food donors with receivers.
- Promote food redistribution.
- Support people in need.
- Encourage sustainable food management.

### Technologies Used
- Python
- Flask
- HTML
- CSS
- Machine Learning
- SQL

### Features
- Food donation management.
- Food redistribution.
- Donor and receiver coordination.
- User-friendly interface.

### Installation

1. Clone the repository.
2. Install the required packages.
3. Run the application.

```bash
pip install -r requirements.txt
python app.py
```
